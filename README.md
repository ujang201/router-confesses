One-line entry for [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) ($2): a home Wi-Fi router excuses itself for dying at the climax of a movie.

The entry line:

> Sorry — I saw the twist coming three episodes ago, panicked, and fainted right on cue. Even routers can't handle who the killer was.

The joke is not technical — no buffering, bandwidth, or firmware-update gag. The router has been watching along with the household all evening, and at the climax it finally learns who the killer is and faints like everyone else in the room.

`main.ts` is a deterministic Node program (no randomness, clock, network, or input) that writes that single line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
